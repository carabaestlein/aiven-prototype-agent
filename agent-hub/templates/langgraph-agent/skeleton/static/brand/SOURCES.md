Unmodified font licenses come from Google Fonts: [Funnel Display OFL](https://github.com/google/fonts/blob/main/ofl/funneldisplay/OFL.txt), [Inter OFL](https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt). Font authors are the Funnel Project Authors and Inter Project Authors respectively.

Current [official stylesheet](https://aiven.io/remix-assets/global-DCPGEbvq.css) declares Funnel Display 800 for display headings and Inter 400/500/600 for body and interface typography. Verified homepage styling uses a near-black `#05080f` background and primary green `#5ffa74` for calls to action. Secondary colors include deep blue `#9ca5ff` / `#7683ff` / `#6f64ff` and light blue `#59d2f4` / `#27bbe9`; the site's accent and highlight tokens reference `#6f64ff`.
